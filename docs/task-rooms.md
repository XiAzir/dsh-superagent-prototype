# 任务群与平级 Worker 协作

个人模式的 **Superagent → 任务群** 提供群聊式任务查看窗口。Web 新建任务后自动进入对应任务群；QQ 等来源已经建立工单的 Thread 也可在此查看。

## 已确定的组织规则

- Router 负责接收人类交互、分派任务和跨任务协调，可以按原任务目标增派平级 Worker。
- Worker 围绕自己的明确分工独立执行；群内采用平级订阅协作。
- 同任务后续工作延续原工单会话；新的独立任务使用独立上下文，Router 按需提供历史引用。
- 共享长期记忆提供来源、有效期、版本与更正传播；通过独立验收的结果可提炼为待确认经验候选，详见[可靠记忆](memory.md)。长期员工档案按实际使用需求继续设计。

这一组织方式以原文 §2.2、§3.2、§3.3 为依据。群聊式监督界面与人类定向输入属于 §8.2 提及的产品交互扩展。

## 消息受众

| 消息 | 模型投递 | 窗口展示 |
| --- | --- | --- |
| R 开启，未提及成员 | Router 判断意图，回答或安排工作 | 显示发送给 R |
| R 开启，提及一位或多位成员 | Router 接收一条原始请求，按指定成员职责统一分配 | 显示成员标签与由 R 协调 |
| R 关闭，提及一位或多位成员 | 直接投递给指定的活跃、已订阅 Worker | 显示成员标签与直达成员 |
| Worker 主动发布协作消息 | 直通同 Thread 的其他活跃、授权订阅者 | 显示 Thread 协作 |
| 普通过程报告 | 留在任务记录，供 Router 按需查阅 | 显示工作记录 |
| 关键结果、阻塞或待人类决策 | 沿既有报告机制交给 Router | 显示相应报告 |
| 工具调用与执行输出 | 留在该 Worker 会话 | 用户展开“执行记录”后按页读取 |

每次输入 `@` 弹出单选列表，选中后收起，可再次输入 `@` 添加其他成员。成员标签保存准确 ID，弹窗可按成员名或任务筛选，正文中的普通 `@` 字符保留原文。R 关闭且尚未选择成员时禁用发送。已结束的成员可保留在标签中，由 R 继续安排。超出当前任务的新独立工作通过 handback 交回 Router。
窗口供操作者监督各类消息；Worker 的历史资源读取同样执行收件范围检查。消息里的“已投递”与模型读取回执分别展示，缺少回执时保留已有可验证状态。

已交付的成果文件在 Router 回复下提供下载按钮。下载以当前群的已发送回执、所属工单、owner 授权及快照摘要共同校验；Web 来源还提供“原任务对话”入口。

## 工具与存储

- Router 的 `orchestrator_delegate` 从现有授权工单增派一个独立分工，继承原 Mandate，并以请求 ID 去重。
- Worker 的 `orchestrator_thread_publish` 将影响共同任务的事实、问题或成果发布到所订阅的 Thread。通知通过确定性代码分发，普通发布保持 Router 的轻量处理路径。
- 同 Thread 的协作发布共用每 60 秒 30 条额度，计数随状态持久保存；幂等重试沿用已有消息。超限时提示合并内容、通过报告汇总关键结论。
- `room_event` 按 Thread、时间、稳定消息 ID 建立分页索引；`room_member` 保留历史参与者，`room_subscription` 保存当前订阅索引。
- 报告修订与原工单保存处于同一 SQLite 事务；消息与投递继续复用持久 Trigger、Input 和 effect。进程重启后可继续读取历史。
- 旧数据首次加载会回填仍可获得的事件、报告与回复。更早的中间报告可从保留的原会话查阅。
- 任务处理暂停时，界面保留历史并提示暂停。已结束或退订的 Worker 在直达路径显示开启 R 的提示；后续新工作由 Router 重新安排。

原生右侧协作群采用成员列表与内容区的左右布局。左侧卡片显示最新摘要，右侧提供按时间排列的阶段简述、协作对话和执行记录。各成员的历史独立分页，两侧分别滚动，阅读旧记录时通过新动态按钮提醒。

Worker 在阶段完成、重要发现、遇到阻碍和开始验证时报告简述，每次实际汇报后重新随机安排 5～15 分钟的总结提醒。长工具运行期间保留一条提醒，在下一安全执行步骤总结已有事实。消息输入支持选图、粘贴、拖放以及纯图片发送，图片通过持久引用提供给 Router 和相关 Worker。

## 验收入口

- `tests/core-collaboration.spec.ts`：定向投递、订阅分发、委派、授权、幂等、停止与持久化。
- `tests/collaboration-tools.spec.ts`：真实 Runtime 工具接线、资源读取隔离、协作与平级委派。
- `tests/task-rooms.spec.ts`：真实 SQLite 事件与报告历史、分页、跨来源任务、执行详情授权与脱敏。
- `tests/panel-rooms.spec.tsx`：任务群窗口、轮询、分页、收件人、暂停与失败重试、按需执行详情。
- `tests/collaboration-messages.spec.ts`：跨任务多成员路由、Router 分发幂等、按成员分页及图片上传与读取。
- `tests/worker-panel-ui.spec.tsx`、`tests/message-composer.spec.tsx`：左右布局、阶段时间线、重复 @、R 开关、图片与草稿。
- `tests/worker-progress.spec.ts`：随机间隔、阶段重置、重启恢复、容量限制和任务生命周期。

构建后重启加载该插件的 DSH 实例，浏览器刷新即可进入新窗口。已有任务、QQ 配置和定时任务沿用原状态目录。
